The first tagged release of **noctalia-installer**: configs and a full-screen terminal installer for the [Noctalia v5](https://docs.noctalia.dev/noctalia/) shell, on every compositor Noctalia supports and every distribution it packages for.

```bash
curl -fsSL https://raw.githubusercontent.com/Abijspy/noctalia-installer/v1.0.0/install.sh | bash
```

This release's installer downloads its configs from this same tag, so the script and configs always match.

## What it does

- **8 compositors:** niri, Hyprland, Sway (blur, corners and shadows on SwayFX), Scroll, Mango, Labwc, Umbriel and KDE Plasma. Pick one or several; with Noctalia Greeter you choose at login.
- **9 distributions:** Arch (with yay or paru for the AUR), Fedora, openSUSE, Debian/Ubuntu, Void, Alpine Edge, Chimera, Gentoo and Solus. On NixOS, Guix and others it writes the configs only.
- **One look everywhere:** every config mirrors the niri one. You get 12px gaps, 20px corners and a Rosé Pine border, plus blur on windows and on Noctalia's bar, panels and notifications wherever the compositor can blur. The same keys work everywhere, and Noctalia settings opens full size (maximized, not fullscreen).
- **Noctalia extras:** Noctalia Greeter with greetd, a floating blurred bar preset, six original 4K wallpapers, overview type-to-launch and Noctalia's polkit agent.
- **Apps:** your choice of terminal (5), file manager (15) and browser (8, including LibreWolf, Brave, Mullvad and Tor Browser). Every keybind follows your choices.
- **Works on a minimal install:** plain bash, straight from the TTY, even as root (it can create your user). Use Esc to quit, the arrow keys to move, Enter to continue and Backspace to go back.

## New in this release

- **`--dry-run`:** lists every package, file and system change, and changes nothing. It needs no root.
- **`--uninstall`:** each install keeps a record in `~/.local/state/noctalia-installer/manifest`. Uninstalling restores your previous configs, greetd config and login manager, and turns off the services the installer turned on. Packages stay installed; it lists them so you can remove them yourself.
- **Desktop services:** turns on NetworkManager, Bluetooth (when there's an adapter) and power-profiles-daemon (on laptops), so Noctalia's widgets work on a minimal install. It skips anything that would clash with what you already use (`--no-services`).
- **NVIDIA:** with NVIDIA's own driver loaded, it turns on kernel modesetting if it's off, and adds niri's fix for high video memory use (`--no-nvidia-fix`).
- **Mango 0.18** option names, translated back automatically for older Mango.
- **Automatic checks** on every push and weekly:
  - shellcheck on the scripts;
  - parsing every config;
  - checking the Mango and Umbriel configs against those compositors' source code;
  - running the whole installer on simulated distros;
  - `niri validate`, `sway -C` and `noctalia config validate` with the real Arch packages.

## Fixes

- On some distributions the installer could exit silently partway through.
- Two runs in the same second overwrote a backup.
- A log file left in `/tmp` by another user stopped the installer.
- The install screen now fits 24-line terminals.

## Good to know

- Installs made before this release kept no record, so `--uninstall` can't undo them.
- Every config has been checked against each compositor's source code and in automated runs. Real logins on Hyprland, Sway, Scroll, Mango, Labwc, Umbriel and Plasma are still to come; please [report anything that doesn't work](https://github.com/Abijspy/noctalia-installer/issues/new?template=bug_report.yml).
