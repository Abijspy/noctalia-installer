The desktop now looks finished from the first login: themes that reach every app, dark GTK and Qt apps, proper fonts, displays at their native resolution and refresh rate, and Luciole, Noctalia's own file manager.

```bash
curl -fsSL https://raw.githubusercontent.com/Abijspy/noctalia-installer/v1.1.0/install.sh | bash
```

## New

- **Colour themes:** pick Rosé Pine (the default), Catppuccin, Tokyo Night, Gruvbox, Nord, Dracula, Kanagawa, Ayu, Eldritch, Noctalia, or **from your wallpaper**. Noctalia's built-in templates recolour window borders on every compositor, GTK and Qt apps, your terminal, Luciole and KDE. With *from your wallpaper*, everything follows the wallpaper when it changes (`--theme=`).
- **Dark apps:** adw-gtk3, Papirus icons, the Adwaita cursor and qt6ct, set up for GTK and Qt (`--no-app-theme` to skip).
- **Fonts:** Inter for the interface and JetBrains Mono Nerd Font for terminals, set as the system's sans-serif and monospace (`--no-fonts`).
- **Standard folders:** Documents, Downloads, Music, Pictures, Videos and the rest (`--no-user-dirs`).
- **Flathub:** optional, with the adw-gtk3 theme for Flatpak apps (`--flathub`).
- **Displays:** each connected display runs at its native resolution and highest refresh rate, with a scale suggested from its size (e.g. 1.5x for a sharp laptop panel). You can take the suggestions, pick one scale, or leave displays alone. It's written for niri, Hyprland, Sway, Scroll, Mango, Umbriel and Labwc (`--scale=`).
- **Keyboard:** a layout variant, the key that switches layouts, and Caps Lock as Escape, Ctrl or swapped with Escape, for every compositor including KDE (`--variant=`, `--switch-key=`, `--caps=`).
- **Luciole:** [Noctalia's file manager](https://github.com/noctalia-dev/luciole) is the default on Arch, built from the AUR (`luciole-git`). It also becomes the Open/Save file picker for other apps, while keeping the previous dialogs as a fallback. Elsewhere, or without an AUR helper, the default stays Nautilus.

## Installer

- New screens: **Colour theme**, **Finishing touches**, **Keyboard options** and **Displays**. The *Keyboard* step is now called *Hardware*, and the Review screen shows the new choices.
- `--uninstall` also removes downloaded fonts and themes and the portal settings, and sets the GTK settings back.
- `--dry-run` lists the theme, app look, keyboard and display settings it would write.

## Fixes

- If `xdg-user-dirs-update` failed, the install stopped partway through.
- Commands run as the target user now always use that user's config folders.

## Checks

- 85 installer test scenarios, now with fake displays and EDIDs.
- GitHub Actions runs `niri validate` and `sway -C` on configs exactly as the installer writes them, with keyboard options, display blocks and the app theme.

## Good to know

- The theme colours come from Noctalia's templates, which run when Noctalia starts. A theme picked earlier in Noctalia's settings overrides the installer's.
- Refresh rates come from each monitor's EDID. When a monitor lists none, Hyprland uses the preferred mode. If a display looks wrong, re-run with `--scale=none` or edit its block at the end of the compositor's config.
- Real logins on compositors other than niri are still to come. Please [report anything that doesn't work](https://github.com/Abijspy/noctalia-installer/issues/new?template=bug_report.yml).
